# Writing

Long-form writing, manuscripts, and reader-facing prose.

Install `writing` from the `tripp-smith-skills` marketplace:

```text
/plugin marketplace add tripp-smith/skills
/plugin install writing@tripp-smith-skills
```

Skills in this ecosystem are one directory deep at `skills/<skill-name>/SKILL.md`.

| Skill | What it does |
| --- | --- |
| `reader-first-communication` | Write titles, headings, and prose for first-time readers: assertion-first hierarchy, conventional domain wording, presupposition checks, and outline continuity. |
